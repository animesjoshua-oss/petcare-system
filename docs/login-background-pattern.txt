============================================================
PATTERN DETAILS:
============================================================
- Paw prints + dog bones scattered randomly
- Color: Pale lavender-blue (#b8c2de)
- Opacity: 38% (very subtle)
- Pattern size: 300x300px (widely-spaced)
- Fixed attachment (stays in place when scrolling)
- Works for both light & dark mode

============================================================
HOW TO USE IN LARAVEL:
============================================================
1. Add to public/css/app.css
2. Or add to login.blade.php in <style> tag
3. Or add to resources/css/app.css and compile with Vite
