## Display layer changes via helper function

Two `displayRoleName()` functions map backend role names to user-visible labels (dashboard/admin/index.php line 309-313, dashboard/admin/users.php line 182-186):

```php
function displayRoleName($roleName) {
    if ($roleName === 'admin') return 'Vet Admin';
    if ($roleName === 'superadmin') return 'Superadmin';
    return ucwords(str_replace('_', ' ', $roleName));
}
```

Role tables call this function instead of rendering raw role_name. The Recent Users table and Manage Users table both pass role_name through displayRoleName(), so admin badges display "Vet Admin".
